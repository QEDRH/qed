5Aristotle (Harmonic) verification

    

      
task, original proof
b4751aa7-9d44-42ea-a20f-b9a52f74f07d project cc840c38-fef3-47f2-943f-3d5ea124127d

    

    
I formalized and proved the statement in Qed/Basic.lean. A run of the quantity is modeled as a sequence q : ℕ → ℤ with q 0 = 1000000000 and, at each step, either q (n+1) = q n or q (n+1) = q n - d for some positive integer d (Qed.IsValidRun). The main theorem Qed.le_initialValue shows that for every n, q n ≤ 1000000000; it follows by induction from the auxiliary step lemma that each operation is non-increasing. The project builds cleanly with no sorry and no extra axioms.

63143c04-5e9b-4572-8bff-304349a3fdd1 project e1e90f7d-9079-4fbc-902b-099062a705b6

    

    
I verified Qed/Basic.lean as submitted. The file builds cleanly against the project's Mathlib pin with no errors and no warnings, and it contains no sorry, admit, or axiom declarations. Both theorems were already complete and correct, so no changes to any definition, statement, or proof were needed:
- Qed.step_le: each step of a valid run does not increase the quantity (case split on the "unchanged" vs. "decrease by a positive integer" alternative).
- Qed.le_initialValue: after any finite number of operations, the quantity is at most 1000000000 (induction on the number of steps, chaining step_le with the initial condition).
I additionally checked the transitive axiom dependencies of both theorems: each uses only propext, Classical.choice, and Quot.sound, i.e. no axioms beyond the Lean/Mathlib standard set. The working tree is unchanged relative to the existing commit, so no new commit was required.
